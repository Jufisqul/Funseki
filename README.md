# One Funseki, Seven Days

Комедийное приключение от третьего лица про одну неделю в странной японской школе 2003 года. В репозитории — Unity-проект вертикального среза «День 1»: катсцена, перемена, урок физры, перемена, конец демо.

## Что нужно

- Windows 10/11.
- [Unity Hub](https://unity.com/download) и редактор **Unity 6000.6.4f1** (Hub предложит его поставить при открытии проекта).
- [Git for Windows](https://git-scm.com/download/win), он должен быть в PATH. Один пакет проекта (unity-mcp, мост для редактора) Unity скачивает по git-ссылке, без Git открытие проекта закончится ошибкой разрешения пакетов.

## Как запустить

1. На странице репозитория нажми **Code → Download ZIP** и распакуй архив. Лучше в короткий путь вроде `C:\Games\Funseki`, у Windows есть лимит на длину пути.
2. В Unity Hub: **Add → Add project from disk** и выбери распакованную папку (в ней лежат `Assets`, `Packages`, `ProjectSettings`).
3. Открой проект. Первый импорт идёт долго, 5–15 минут: Unity строит папку `Library`.
4. Когда редактор откроется, выбери в меню **Tools → Funseki → Core → Play From Bootstrap**. Можно и так: открыть сцену `Assets/_Project/Scenes/Bootstrap.unity` и нажать Play. Запуск из других сцен не работает, потому что сервисы игры создаёт Bootstrap.
5. В главном меню нажми «Новая игра».

Если Play будто застыл, щёлкни по окну Game: в фоне игра стоит на паузе.

## Управление

| Действие | Клавиатура и мышь | Геймпад |
|---|---|---|
| Ходить / камера | WASD или стрелки / мышь | левый / правый стик |
| Бег | Shift | нажать левый стик |
| Прыжок | Пробел | A |
| Вид от первого лица | удерживать F | удерживать LB |
| Взаимодействовать | E | X |
| Сменить героя | Tab | Y |
| Способность героя | Q | B |
| Пауза | Esc | Start |

## Структура

Код и данные игры — в `Assets/_Project` (Scripts, Data, Scenes, Art, Prefabs, Audio). Подробности — в `CLAUDE.md`.

`Assets/_Trash` — файлы, отложенные при уборке проекта на удаление (см. `Docs/cleanup_report.md`). На игру они не влияют.
